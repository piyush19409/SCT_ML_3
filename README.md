# 🐱🐶 Cats vs Dogs Classification using SVM

## 📌 Project Overview
This project implements a Support Vector Machine (SVM) model to classify images of cats and dogs using a subset of the Kaggle dataset.

## 🎯 Objective
To build a machine learning model that can accurately distinguish between cats and dogs.

## 🛠️ Technologies Used
- Python  
- OpenCV  
- NumPy  
- Scikit-learn  

## 📂 Dataset
- Source: Kaggle Dogs vs Cats dataset  
- Subset used (~193 images)

## ⚙️ Methodology
1. Load images  
2. Resize to 64×64  
3. Convert into feature vectors  
4. Split dataset into training and testing  
5. Train SVM model  
6. Evaluate performance  

## 📊 Results
- Total Images: 193  
- Accuracy: ~87%
